# Fonts for link-preview images

Schibsted Grotesk (400, 600) and Sometype Mono (400) in WOFF, as served by Google Fonts in November 2026. Both families are licensed under the SIL Open Font License 1.1. They are read from disk by the Open Graph image routes, because the image renderer accepts TTF, OTF and WOFF files rather than the WOFF2 files the app itself loads.
